## New Features

### A New Look

Budget Board has received a visual refresh to improve consistency and usability across the app.

Budget Board uses [Mantine](https://mantine.dev) for its user interface components.
This update creates a wrapper library around the Mantine components, with standardized customizations applied consistently across the app's user interface.
Things like color palettes, typography, padding, hover effect, and other visual and interactive aspects are now consistently applied across all components.

### Budget Rollovers

A new feature allows budget categories to carry over unspent or overspent amounts to the next month.
This can be used to maintain budget continuity across months, allowing users to save unspent funds towards larger purchases or cover overspending from previous months.

### Transaction Trends

The Spending Trends chart has been replaced with a configurable Transaction Trends chart.
Previously, the Spending Trends chart only displayed a running total of all spending, without any form of customization.
The chart has been updated to allow users to choose whether to view income or expenses and select which categories to include.
The chart is available on the Trends page and as a dashboard widget.

### Account Filtering for Metrics

The Metrics widget now supports filtering by account, making it easier to focus on the financial data for a particular account.

### Transaction Notes and Tags

The transaction creation form now includes notes and tags.
