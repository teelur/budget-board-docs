# Trends

The Trends page helps you analyze how money moves through your accounts and transaction categories over time.

## Transaction Trends Chart

The Transaction Trends chart compares income or spending across the months you select. Use the month controls to choose one or more months.

Select one or more categories to focus the chart on them. If no categories are selected, use the transaction type menu to choose **Spending** or **Income**. The chart is also available as a [dashboard widget](/docs/features/dashboard).

## Cash Flow Sankey Chart

The Cash Flow Sankey Chart visualizes the flow of money between transaction categories. Use it to see how income and spending move through your budget and which categories contribute to the overall cash flow.

The chart is also available as a [dashboard widget](/docs/features/dashboard).
