# Recurring Transactions

Recurring transactions are transactions that repeat on a regular schedule, such as rent, utilities, subscriptions, or loan payments.

## Managing Recurring Transactions

Open the recurring transactions sub-page from the `Transactions` section of the sidebar to create and manage recurring transaction rules.

### Creating a Rule

A recurring transaction rule describes how Budget Board identifies a recurring transaction. Configure the rule using the transaction's:

- **Account**
- **Merchant Name**
- **Category**
- **Cadence**
- **Amount**

### Marking Transactions as Recurring

You can mark transactions as recurring from the transactions page. Budget Board uses marked transactions to predict and identify future occurrences.

## Predicted Transactions

Budget Board uses recurring transaction data to predict future occurrences. These predictions appear on the [Budgets](../budgets.mdx) page as an estimate of spending for the month ahead.

Predictions help you account for expected recurring spending when reviewing a budget. They are estimates based on recurring transaction data, while your actual budget progress continues to reflect transactions recorded in your accounts.
